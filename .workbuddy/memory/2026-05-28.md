# 2026-05-28

## 修复 Qdrant 本地模式双客户端文件锁冲突

**问题**：`rag/ingest.py` 执行时报 `RuntimeError: Storage folder ./data/qdrant_db is already accessed by another instance of Qdrant client`

**根因**：`ingest.py` 中第62行创建了第一个 `QdrantClient` 做 Collection 删除/创建操作，第82行调用 `get_or_create_vector_store()` 内部又创建了第二个 `QdrantClient`，两个实例指向同一 `./data/qdrant_db` 路径，Qdrant 本地模式的文件锁只允许一个客户端访问。

**修复**：在 `ingest.py` 第77行后添加 `client.close()` 释放第一个客户端的文件锁。
